🎯 What Does This Do?

Are you tired of seeing random plugin names and descriptions in a foreign language when you open ChatGPT or Codex? This tool simply replaces the text on the plugin store page inside your desktop app with a version you can actually understand. It works like magic — no need to edit any files inside the app, no special technical skills.

It’s a local-first app that runs directly on your computer. It translates the plugin store interface and plugin descriptions into a language you choose. It supports 15 different languages including Chinese, English, Spanish, French, Japanese, German, Korean, and more.

🖥️ Works on Mac, and Windows (experimental)

If you use a Mac (macOS), you are fully supported. If you use Windows, there is experimental support — it’s mostly working, but a few rare edge cases might occur. Still, you can try it out, and the basic translation will work perfectly on most setups.

💡 Note: This tool works directly with the ChatGPT desktop app and the Codex desktop app. It does not attempt to change your system language or modify the core app files. Simply open your app and enjoy a familiar interface.
